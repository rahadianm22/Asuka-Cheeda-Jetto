# antislop report 002 (2026-09-28): "heboh" gift redesign

Mode: During. Direction from the owner, transcribed in `DESIGN.md`.

Design Read: fan gift site for a VTuber with a vet-doctor persona, for Jetto and her fans, in a "clinic records, turned up loud" language, dial ENERGY 3 / RHYTHM 3 / MOTION 3.

## What was added, and why each exists

| Element | Purpose (R-31) |
|---|---|
| Giant "JETTO" in Archivo wdth 125, letters rise in one by one | Single focal point of the page: it is her gift, her name leads |
| Clinic stamp in the hero, rotates with scroll | Identity motif (vet seal); motion is tied to the reader's scroll, not an idle loop |
| Two crossing bands that react to scroll speed | Broadcast-banner energy for a streamer; answers the audit-001 ticker question (kept, now reader-driven) |
| Greeting with a hand-drawn underline on "Jetto" | Emphasis on her name, drawn once |
| Patient file: taped paper, tilted, stamped "Dokter jaga" | The clinic motif made physical; the only element with a shadow, because it is the only "object on the desk" |
| Pose placed beside the file | She holds a clipboard in that art, so she stands next to her own file |
| Cheeda: click to pat (wiggle + counter); Cipet: click to carry (toggle) | Their own lines ask for exactly this; real behaviour, not decoration (R-26) |
| Section index "No. 01..06" + wide display headings, alignment varies | File-index voice; RHYTHM 3 composition changes between sections |
| Stats count up once, in view | Celebrates the real live numbers; server renders the final value |
| Newest cover: lavender rail, big outlined serial | The newest upload is what a returning fan checks |
| Support as a full lavender panel | The page's one full accent moment, on the action that helps Jetto |
| Tactile hover (shift + hard shadow) on every link | One shared gesture, like pressing a stamp |
| Giant "WOOF WOOF~" footer, letters hop on hover; "Hadiah untuk Jetto, dari" | Her catchphrase as sign-off; states honestly that this is a gift |
| Paw burst on click | Husky-vet signature; skipped for keyboard clicks and reduced motion |
| Scroll progress line | Orientation on a long page |

## Owner override (R-37)

## Verification
- `npm run build` clean; production server 200.
- Rendered HTML: 0 em dashes, 1 h1, 0 buttons nested in links, 2 character buttons.
- Screenshots (headless Edge) at 1440px and at a true 390px (iframe, because headless Edge has a 492px minimum window). Found and fixed from screenshots: greeting squeezed to one word per line with the pose covering the subtitle (R-25), "!" wrapping away from "Jetto", character art overflowing its frame, stamp covering the file title on mobile, top bar wrapping on mobile.
- Contrast computed with the WCAG formula for every new pair; one failure caught and fixed (sub text on lavender 3.27:1, replaced with #3a2c44 at 5.71:1).
- Reduced motion: MotionConfig `reducedMotion="user"`; scroll-linked hero values, band drift and paw burst check it explicitly.
- Not done: clicking through by hand in a real browser, testing on a real phone. The pat/carry buttons, play buttons and language toggle were checked by code, not clicked.

## Follow-up: type scale reduced (owner request)
Owner asked for normal website text sizes so the design stays comfortable. Hero name 280px to 96px max, section titles 84px to 40px, stats 104px to 44px, footer "WOOF WOOF~" 200px to 60px, bands 40px to 19px; Archivo width eased from 125 to 108-115. ENERGY dial lowered to 2. Rebuilt and re-checked by screenshot at 1440px and 390px.

## Follow-up: paw cursor (owner request)
- Paw is a native CSS cursor (SVG, lavender with a dark outline so it reads on lavender and on paper); a lighter "ready to press" paw on links and buttons. No JS, so no lag, and it still works with reduced motion.
- A springy ring follows the paw (grows on links, squeezes on press) and footprints trail the path, alternating left and right. Both only run for a mouse with `(hover: hover) and (pointer: fine)` and no reduced-motion preference; touch screens are untouched. The ring hides when the mouse leaves the window or enters a YouTube iframe.
- Verified with a temporary same-origin test page that dispatched pointer events (deleted afterwards): both cursor SVGs render, ring follows, footprints appear. The native cursor itself cannot be captured by a headless screenshot, so its on-screen look was checked from the rendered SVGs, not a live mouse.
